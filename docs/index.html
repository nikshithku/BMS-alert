        How to create the token
        1. Open fine-grained token settings.
        2. Under Repository access, pick only this one repo.
        3. Under Permissions → Repository, set Issues to Read and write. Add Actions: Read and write if you want the “Check now” button.
        4. Set an expiry — 90 days is sensible — then generate and paste it here.
        Where this token lives. It's kept in this browser's local storage and sent only to api.github.com. It is never committed. Anyone with access to this browser profile can read it, so scope it to this single repo and give it an expiry.

        Stop this watch?

        This closes the issue, so checks stop. You can reopen it on GitHub later.
